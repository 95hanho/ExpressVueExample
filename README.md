# ExpressVueExample

Vue와 Node.js Express를 활용해 CRUD API 연동을 학습한 기본 프로젝트입니다.

## 주요 기능

- 데이터 목록 조회
- 데이터 추가
- 데이터 수정
- 데이터 삭제
- Vue 화면과 Express API 연동

## 기술 스택

- Frontend: Vue, Vue Router, Axios, JavaScript, Bootstrap
- Backend: Node.js, Express
- Database: MySQL

## 프로젝트 구조

```bash
frontend   # Vue frontend
nodeVue    # Express backend
```
